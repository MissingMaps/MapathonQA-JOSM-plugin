Bundled fonts for the MapathonQA PDF report (embedded by ReportWriter via OpenPDF).

  Nunito-Regular.ttf, Nunito-SemiBold.ttf, Nunito-Bold.ttf, Nunito-ExtraBold.ttf
      Nunito, (c) 2014 The Nunito Project Authors - https://github.com/googlefonts/nunito
      Latin-subset static instances as served by fonts.gstatic.com.

  Fraunces-Head.ttf   (Fraunces 9pt optical, SemiBold)
  Fraunces-Num.ttf    (Fraunces 72pt optical, SemiBold)
      Fraunces, (c) 2018 The Fraunces Project Authors - https://github.com/undercasetype/Fraunces

Both families are licensed under the SIL Open Font License 1.1 - see NUNITO-OFL.txt
and FRAUNCES-OFL.txt in this folder.

NOTE: the Nunito files are the Latin subset - basic Latin plus Western-European
accents. Mapathon names in Latin-extended (e.g. Krakow's 'o' with stroke), Cyrillic,
Greek or non-European scripts will not render. Swapping in a fuller Nunito build (or
a Noto fallback) is a drop-in change if that becomes necessary.
